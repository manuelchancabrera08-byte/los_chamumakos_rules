# Los Chapumakos

Repositorio maestro de reglas, personajes, prompts y aprendizajes para la producción de **Los Chapumakos**.

## Objetivo
Crear videos cortos de humor cotidiano con personajes recurrentes y una identidad visual y sonora consistente.

- **Chapu**: cliente ingenuo / confiado.
- **Mako**: dueño, empleado o trabajador vivo que siempre tiene una respuesta lista.

## Regla de oro
**Situación cotidiana + pequeña injusticia o absurdo + respuesta rápida + remate seco.**

## Formato base
- Vertical 9:16.
- Bloques de 15 s; una historia puede ocupar 2 bloques para ~30 s.
- Cámara fija desde el POV del cliente/interlocutor.
- Realismo físico y visual estricto.
- Nada aparece, desaparece, duplica, cambia de forma o se mueve sin causa física.
- Los letreros y branding `CHAPUMAKOS` deben permanecer estables y legibles.

## Flujo de trabajo
1. Definir situación cotidiana.
2. Elegir personaje principal.
3. Escribir diálogo corto.
4. Crear y validar imagen de referencia.
5. Generar clip.
6. Revisar errores.
7. Registrar aprendizaje en `09_LEARNINGS_LOG.md`.
8. Actualizar reglas maestras si aplica.
9. Generar siguiente versión.
10. Marcar versión aprobada.

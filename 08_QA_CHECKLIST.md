# Checklist QA antes de aprobar un clip

## Personaje
- [ ] Rostro correcto.
- [ ] Pelaje correcto.
- [ ] Cola correcta.
- [ ] Proporciones correctas.
- [ ] Tamaño no humano.
- [ ] Uniforme completo.
- [ ] Sin extremidades duplicadas.

## Cámara
- [ ] Toma fija.
- [ ] Sin zoom.
- [ ] Sin paneo.
- [ ] Sin reencuadre.
- [ ] Sin drift del fondo.

## Escenario
- [ ] Auto no cambia.
- [ ] Herramientas no cambian.
- [ ] Nada aparece.
- [ ] Nada desaparece.
- [ ] Nada se duplica.
- [ ] CHAPUMAKOS no cambia.
- [ ] Letras legibles.

## Voces
- [ ] Cliente masculino joven.
- [ ] Mako masculino mayor.
- [ ] Timbres claramente diferentes.
- [ ] Mako grave, sereno, confiado, con picardía.
- [ ] Cliente no usa voz de Mako.
- [ ] Mako no dice las líneas del cliente.
- [ ] Mako mantiene boca cerrada cuando habla el cliente.

## Diálogo
- [ ] Frases cortas.
- [ ] Ritmo ágil.
- [ ] Mako responde rápido.
- [ ] Remate seco.
- [ ] No se explica el chiste.

## Física
- [ ] Contacto correcto.
- [ ] Gravedad creíble.
- [ ] Cola natural.
- [ ] Manos coherentes.
- [ ] No hay teletransportación.

# EP-001 — Mako mecánico

## Concepto
Cliente pregunta por su auto en el taller. Mako siempre tiene una respuesta.

## Parte 1
- CLIENTE: “¿Y mi carro?”
- MAKO: “Ahí va, jefe.”
- CLIENTE: “Lleva tres días ahí arriba.”
- MAKO: “Por eso va volando.”
- CLIENTE: “¿Ya encontró la falla?”
- MAKO: “Sí.”
- CLIENTE: “¿Cuál era?”
- MAKO: “Que estaba fallando.”

## Parte 2
- MAKO: “Pues mejor regrese mañana.”
- CLIENTE: “¿Y si mañana no está?”
- MAKO: “Pues regrese pasado.”
- CLIENTE: “Me voy a quejar.”
- MAKO: “Pues quéjese con el gerente.”
- CLIENTE: “¿Y dónde está?”
- MAKO: “Hoy no vino. Venga mañana.”
- MAKO: “Ya, adiós... ¡siguieeeente!”

## Problemas detectados durante producción
- Auto deformado al mover cámara.
- Letreros alterados.
- Voces del cliente y Mako demasiado parecidas.
- Voz de cliente llegó a salir femenina.
- Cola incorrecta en una imagen de referencia previa.
- Diálogos iniciales demasiado largos.

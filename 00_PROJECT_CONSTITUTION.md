# Constitución del proyecto

## Identidad
**Los Chapumakos** es una serie de comedia corta protagonizada por monos realistas con comportamiento social humano, manteniendo anatomía, tamaño y física de mono.

## Principios no negociables

1. **Realismo primero**
   - Los monos deben parecer animales reales.
   - No deben ser de altura humana.
   - Pueden tener postura, gestos y actitud humanas, pero conservan anatomía de mono.

2. **Humor cotidiano**
   - Las situaciones deben sentirse familiares: taller, panadería, barbería, tienda, restaurante, paquetería, telefonía, banco, etc.

3. **Diálogo seco**
   - Frases cortas.
   - Respuestas rápidas.
   - Cero discursos explicativos.
   - El remate debe parecer lógico para el personaje aunque sea absurdo para el espectador.

4. **Cámara fija**
   - POV del cliente o interlocutor.
   - Toma bloqueada.
   - No zoom, paneo, tilt, dolly ni reencuadre.

5. **Continuidad estricta**
   - Nada aparece de la nada.
   - Nada desaparece.
   - Nada se duplica.
   - Nada cambia de forma.
   - Branding y letreros no se deforman.

6. **Aprendizaje acumulativo**
   - Cada error detectado se documenta.
   - Los prompts futuros deben incorporar las correcciones aprendidas.
   - No se vuelve a introducir un error ya resuelto.

# Reglas de continuidad visual

## Regla principal
El primer frame de la imagen de referencia es la autoridad visual.

Cada prompt nuevo parte de ESA imagen concreta. No asumir continuidad con un clip anterior salvo que el usuario lo pida expresamente.

## Debe permanecer idéntico
- Personaje.
- Rostro.
- Pelaje.
- Patrón de cabeza.
- Ojos.
- Párpados a medio ojo / semicerrados cuando corresponda a Mako.
- Cola.
- Proporciones.
- Uniforme completo.
- Calzado.
- Iluminación.
- Fondo.
- Posición aparente de objetos.
- Vehículos.
- Herramientas.
- Letreros.
- Branding `CHAPUMAKOS`.

## Mako debe seguir viéndose como mono real
- Mono capuchino pequeño y realista.
- Anatomía animal real: torso, hombros, brazos, piernas, manos, pies, hocico, orejas y cola.
- Debe verse como un mono real haciendo acciones humanas, NO como un humano vestido de mono.
- Evitar cuerpo humanoide, manos humanas, postura de superhéroe o acabado de mascota/CGI.
- Pelaje con dirección, textura, suciedad y reacción a la luz coherentes con el escenario.

## Prohibido
- Aparición espontánea de objetos.
- Desaparición de objetos.
- Duplicación.
- Morphing.
- Cambios de escala.
- Cambios de forma.
- Deformación del entorno.
- “Respiración” del fondo.
- Cambio de letras.
- Logos que se reescriben.
- Herramientas que cambian de lugar sin contacto físico.
- Objetos que desaparecen para liberar las manos del personaje.

## Regla especial para objetos en las manos
Si la imagen de referencia muestra a Mako sosteniendo una tabla, herramienta, producto, teléfono u otro objeto y después necesita usar ambas manos:
1. describir explícitamente qué hace con el objeto;
2. moverlo con contacto físico visible;
3. colocarlo, apoyarlo o soltarlo en una superficie lógica;
4. mantenerlo visible y estable después;
5. no permitir que desaparezca, teletransporte o cambie de forma.

Preferir acciones simples y robustas: bajar → apoyar → soltar → objeto permanece. Evitar lanzar objetos salvo que el chiste dependa de ello.

## Física
Todo movimiento debe tener causa:
- Gravedad consistente.
- Contacto correcto con superficies.
- Manos y pies con apoyo real.
- Peso corporal y equilibrio creíbles.
- Cola con movimiento natural ligado al balance.
- Ropa siguiendo el cuerpo.
- Nada atraviesa objetos.
- Nada se desliza, flota o cambia de sitio sin fuerza/contacto visible.
